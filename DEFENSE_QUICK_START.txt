8. TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════════

Port 3000 already in use?
  Get-NetTCPConnection -LocalPort 3000 | Stop-Process -Force

Database issues?
  Remove-Item database.sqlite -Force
  node sync-db.js
  node seed-test-users.js

Server won't start?
  npm install
  npm run xian
