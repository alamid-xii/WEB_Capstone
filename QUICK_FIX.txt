ERROR: Access denied for user 'root'@'localhost' (using password: NO)

SOLUTION: Follow these 3 steps

================================================================================
STEP 1: START MYSQL IN LARAGON (1 minute)
================================================================================

1. Open Laragon application
2. Look at the left sidebar - find "MySQL"
3. If MySQL shows RED icon (stopped):
   → Click MySQL to start it
   → Wait for it to turn GREEN ✅
4. If MySQL is already GREEN:
   → MySQL is running, continue to Step 2

================================================================================
STEP 2: VERIFY DATABASE EXISTS (1 minute)
================================================================================

1. In Laragon, click "Admin" button
2. This opens phpMyAdmin at http://localhost/phpmyadmin
3. Look for database named "backend" in the left sidebar
4. If "backend" database exists:
   → Continue to Step 3
5. If "backend" database DOES NOT exist:
   → Click "New" on the left
   → Type: backend
   → Click "Create"

================================================================================
STEP 3: RESTART BACKEND SERVER (1 minute)
================================================================================

1. In your terminal, press: Ctrl+C
   (This stops the current server)

2. Wait for it to stop completely

3. Start server again:
   npm start

4. Wait for this message:
   ✅ Server running on port 3000

5. If you see that message → SUCCESS! ✅

================================================================================
VERIFY IT WORKS (1 minute)
================================================================================

Open new terminal and run:
   node test-all-endpoints.js

Expected: All 21 tests pass ✅

================================================================================
IF IT STILL DOESN'T WORK
================================================================================

Try these in order:

1. Check if MySQL is actually running:
   - Open Laragon
   - MySQL should have GREEN icon
   - If RED, click to start it

2. Check if port 3306 is available:
   - Open Command Prompt
   - Type: netstat -ano | findstr :3306
   - If nothing shows, port is free

3. Restart Laragon completely:
   - Close Laragon
   - Wait 10 seconds
   - Open Laragon again
   - Start MySQL

4. Reset database:
   - Open phpMyAdmin
   - Drop database "backend"
   - Create new database "backend"
   - Run: node run-migrations.js

5. Check .env file:
   - Should have: DB_PASSWORD= (empty)
   - Should have: DB_HOST=127.0.0.1
   - Should have: DB_PORT=3306
